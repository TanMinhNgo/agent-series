# Library Collections Backlog

P1.3 chỉ tạo Knowledge Collections cho PDF RAG trong từng Project. Artifact và các file Library khác vẫn dùng luồng riêng để tránh trộn nguồn chưa index vào câu trả lời.

## Hướng mở rộng sau P1.3

- Tạo collection tổng quát cho PDF, DOCX, XLSX, PPTX, Markdown, CSV, JSON và ảnh có OCR.
- Chuẩn hóa trạng thái index theo từng loại file và version artifact.
- Cho phép một chat chọn collection Library, với quyền xem nguồn và citation nhất quán.
- Bổ sung tìm kiếm/lọc theo loại file, tag, Project và trạng thái index.

Chỉ bắt đầu phần này sau khi P1.3 được kiểm chứng end-to-end với PDF, collection và citation mở đúng trang.
